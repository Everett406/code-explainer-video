# 通用制作提示词

把方括号内容替换成本次需求。用户已提供素材时，保留“素材规则”部分。用户只要求制作视频时，按提示词执行，不要只把提示词返回给用户。

```text
做一个讲解【主题】的视频，使用代码实现，渲染 MP4。

【目标与受众】
- 面向【受众】，看完后理解【核心结论】。
- 必须讲准【事实、数字、概念】。
- 默认使用中文。画幅为【16:9／9:16】。
- 默认 1920×1080、30 fps。时长按内容确定。
- 添加旁白字幕，不生成配音。
- 【可选：添加音乐、音效或用户录音】。

【工作方式】
1. 先写简明旁白和分镜，再写画面代码。
2. 用同一份时间轴驱动旁白、字幕、镜头和动画。
3. 先做关键帧和预览，集中修改后再导出 MP4。
4. 保留可编辑源码。不要只交一个网页。
5. 不强制等待我确认，除非我明确要求样片确认。

【画面规则】
1. 保持画面干净整洁。禁止文字堆砌。
2. 删除小字、装饰文字、角标、章节编号和无关中英对照。
3. 只保留必要文字，并使用大号字体。
4. 内容太多时拆镜头，不靠缩小字号解决。
5. 使用统一的图标库。默认使用 Lucide。
6. 用图标和矢量图形解释内容，不用 emoji 充数。
7. 普通图标不要手绘 SVG。定制图形留给特殊主体和图表。

【运镜与转场】
1. 这是视频工程，不是静态网页展示。
2. 内容讲到什么，镜头就呈现什么。
3. 使用有目的的推、拉、平移、跟随、聚焦和景别变化。
4. 连续关系可以使用大画布，让镜头移动到对应位置。
5. 话题或场景变化时使用独立镜头，不强求一镜到底。
6. 用形变、遮罩、遮挡和匹配构图完成转场。
7. 不要预先摆好全部内容，再只做整页缩放。
8. 不要滥用匀速运动、默认淡入淡出和无意义特效。

【素材规则】
1. 先检查我提供的全部素材，再决定分镜。
2. 优先使用我的图片、视频、录音、字体和数据。
3. 不使用无关素材替换我的内容。
4. 图片保持比例，视频按内容裁剪，图表使用真实数值。
5. 我提供录音时，按原录音对齐字幕和动画，不改用 TTS。
6. 缺图时使用统一图标或矢量图形。
7. 外部素材需核实许可，并记录来源。

【技术要求】
1. 新建项目默认使用 Remotion + React + TypeScript。
2. 改造现有 Opus 案例时，沿用原渲染链。
3. 任意一帧都由时间确定。随机效果使用固定种子。
4. 不使用实时录屏代替逐帧渲染。
5. 素材和字体在渲染前加载完成。
6. Remotion 中不用 CSS 动画或 transition 驱动成片。

【验收与交付】
1. 检查每个镜头的关键帧和转场连续帧。
2. 检查文字溢出、遮挡、黑帧、字体回退和素材加载。
3. 检查字幕与讲解同步，并留足阅读时间。
4. 用 ffprobe 核对分辨率、帧率、时长和解码情况。
5. 默认交付 H.264 MP4，并保留可编辑工程。
6. 只报告实际完成的检查，不宣称一次达到完美质量。
```
